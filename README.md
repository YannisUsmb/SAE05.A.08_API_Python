# SAE05.A.08_API_Python

## Installation du projet.

1. ```git clone https://github.com/YannisUsmb/SAE05.A.08_API_Python```
2. Vérifier que Docker Desktop est ouvert.
3. ```docker-compose up```

## Installer son environnement.

1. ```python -m venv .venv```
2. ```./.venv/Scripts/pip install -r requirements.txt```
